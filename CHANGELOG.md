# Changelog

## 1.1.1

- Fixed Python files gaining an automatic indentation when Enter was pressed.
- Python now starts new lines without synthetic or inherited indentation; use Tab for blocks.
- Updated the dashboard version label.
- Added GitHub publishing documentation, screenshots, and release notes.

## 1.1.0

- Added an embedded CPython 3.12 runtime powered by Chaquopy.
- Added on-device Python execution with captured stdout, stderr, and tracebacks.
- Added interactive `input()` dialogs.
- Added sibling imports, relative file access, `sys.argv`, and `__main__` support.
- Added a native Python output screen with copy and run-again actions.
- Added Python, Chaquopy, Sora, and Monarch license notices.
- Increased the APK size to include arm64-v8a and x86_64 runtimes.

## 1.0.0

- Initial native Android editor release.
- 19 languages with Sora Editor and Monarch grammars.
- Tabs, search and replace, SAF workspaces, playground, live preview, and two themes.
