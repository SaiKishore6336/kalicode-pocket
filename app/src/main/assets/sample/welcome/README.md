# Welcome to KaliCode Pocket

This folder is your built-in playground. It is a real project stored in the
app's private storage, so you can edit it, run the HTML preview, and experiment
without granting storage permissions.

## Try this

1. Open `index.html` and tap **Preview**.
2. Change the headline in `index.html`.
3. Open `style.css` and change `--mint`.
4. Preview again to see the result.
5. Open `main.py` to see Python highlighting and smart indentation.

## Languages

KaliCode Pocket includes native syntax support for Python, JavaScript,
TypeScript, HTML, CSS, JSON, Markdown, Java, Kotlin, XML, YAML, Shell, SQL,
C/C++, Go, Rust, PHP, Ruby, and Lua.

Open a real folder from the home screen to edit your own projects. Changes are
saved back through Android's Storage Access Framework.

## Keyboard tips

- **Tab** inserts spaces using your configured tab size.
- **Ctrl/Cmd + S** saves the active file.
- Use the symbol row above the keyboard for fast brackets and quotes.
- The Find bar supports case, whole-word, and regex search.

Made for small screens and low memory.
